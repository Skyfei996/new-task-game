- **病根＝目标无锚点**：全站 UI 无任何「我该干什么」的常驻面（工具栏仅 🆘🗂👥🎒❓↺；弹层无相关入口，`prototype/index.html`）；目标只存在于读过的台词里，跨 3 层 17 房靠记忆推进 ⇒ 掉线。

- **求助入口不救急**：🆘 只在 `deadEnd()`（完全无可执行动作）时触发（`engine.js:890-896`／`showStuck() :2161`），且面板内容只有「回到安全点／重开本关」两个出口，不给方向；❓帮助只讲规则不讲进度。
