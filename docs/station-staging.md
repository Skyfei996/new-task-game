## 0. 口径与图例

**七列**（按标准 §2.3）：背景 ｜ 镜头·焦点 ｜ 元素进出 ｜ 主面板 ｜ 氛围 ｜ 界面变化 ｜ 音效钩子。
每格必须有内容；无演出变化写「无变化」，不留空。

**记法**：

- `T##` = `art/status.md` 的任务号场景图（`T13` 即「⑫反应堆舱内景」）。
- `（现 deckX）` = 该节点**现在用哪张图跑**（临时替代）；到货后的切换规则见 §4。
- `〔新〕` = 原型界面尚没有、需要新增的界面行为（汇总见 §5）；未标注 = 现有能力或纯内容变化。
- `CG-01…CG-07` = 本表派生的拟新增特写/插图；`CG-08`、`T06-ext`、`T20/T25-ext` 为补遗（清单见 §3）。需要新画的 CG 均标 `〔需新图〕`；未标注的图号都是已有/已下单资产。
- 音效列按标准写好**钩子**，供未来音效线派生（音效 v0.1 不做，见 `design-station-v1.md`）。

**镜头语言词表**（关键节点必须使用其中之一）：
推近（轻推）｜特写｜拉远｜慢镜｜黑屏｜震动｜定格｜光涌（亮场过曝感）。

**演出原则**（对标准与 B02 判据的执行口径）：

1. **任何操作有反馈**（B02·E 判据）：资源变动 → 资源格闪动 + 飘字；获得 → 入包提示；知识 → 线索卡〔新〕；移动 → 场景切换提示。
2. **首访给揭示、复访给分叉**：重复进入房间读 `tIf` 分叉正文（3/4/5/7/9/10/11/12/15/19 十处），一次性演出**不重演**。
3. **一次性演过不重演**：`once` 选项执行后隐藏，其演出不再触发（对应 B02·D 的 once 盘点）。
4. **权威分界**：节点结构与机制字段以 `design-station-nodes.md`（§5 节点表 / §9.5 机制落点）为准；文案以 `station-story-bible.md` §7 为准；数值以 `design-station-v1.md` §8 为准。本表只写「画面与界面怎么变」，不新增台词、不定义数值。
