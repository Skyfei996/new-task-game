## 人设① 第一次摸到这款游戏的普通人 · 林小晨
结局：💀 **氧气耗尽（失败）**——死在启动反应堆前一步。
> `💀「眼前一黑……」氧气表的指针滑到了零。你听见很远的地方有人在喊你的名字——在『晨星号』上，这是最危险的声音。（提示：睡眠舱的氧气瓶、医务室的氧气站、中层大厅的补给柜，都是一次性补给，别忘了拿。）`——三处补给我**全拿了**，仍然不够；且全程不知道剩余量。

### 场景首入：我想干什么、能不能干
| 场景 | 我现在想干什么 | 能不能干 |
|---|---|---|
| 食堂（开局） | 搞清状况、求救 | 三个选项都能点，但不知道"中央大厅"是哪儿，也不懂为什么这时候洗碗 |
| 中央大厅（三层通用） | 找人问话 | 能走各房间、坐电梯；进入中层时被动 `+5 点氧气`，没搞懂怎么回事 |
| 指挥舱 / 糖糖带路 | 多问点东西 | 能问；它张口就把保险柜密码教了 |
| 实验室 | 找老布聊芯片 | 有一个灰选项"（知道爬道走法的你）"，点不了 |
| 老布的委托 / 维修区 | 找到工具箱、救同型号机器人 | 工具箱要灯、电池要买；拖机器人写着"武力值 0 < 1" |
| 站长室 | 用密码开柜 | 不行——"还差一道门道" |
| 通讯舱 | 追那个打电话的人 | 能查货单；有个"对全站广播"的按钮，没敢按 |
| 仓库 | 拿冷却剂 | 桑尼挡着、门禁锁着；只能拿"封口费"或硬来 |
| 气闸舱 / 站外 | 修电力 | 能出舱，一次 `-20 氧气`；面板要工具 |
| 睡眠舱 | 翻自己的柜子 | 能翻——手电、工牌、氧气瓶（+10） |
| 医务室 | 救人 | 要医疗包（在健身房）；老氧气站 +5 |
| 健身房 | 找人帮忙 | 铁头要"掰手腕"；急救箱"得先让他服气" |
| 底层核心区各舱 | 修电、开堆 | 复电闸门、反应堆舱都能进；反应堆每次 `-10 氧气` |
| 结局 | —— | 💀 |

### 每 10 步 · 当下心里话（原话）
- 第 10 步："我手里就攥着控制芯片，老布还在那儿念'没有工具箱，芯片的事免谈'——大哥，你看看我手里啊？！还有，那个灰按钮骗人：糖糖都教过我怎么爬爬道了，它还说我不知道；非得我真钻一趟（-10 点氧气）才算'知道'。"
- 第 20 步："出舱一次就没了 20 格氧气，可状态栏还是'还好'。我这是拿什么在换？我根本不知道自己还剩多少。"
- 第 30 步："我洗了三个碗才挣 6 枚星币，氧气倒掉了 15——结果商店还是没地方买。我到底在攒钱给谁看？"
- 第 40 步："工牌、手电、手套、授权卡……我什么都拿到了，可商店那行字还是冷冷挂在那里，不告诉我怎么花钱。"
- 第 50 步："桑尼翻脸了，无人机顺走了我 8 枚星币。但'直接动手搬'是我唯一能点的选项——我没有别的路。"
- 第 60 步："焊枪的火花很漂亮，电回来了。可我怎么也没想到，真正让我倒下的不是反派、不是谜题，是我一直看不见的那一格氧气。"
- 第 70 步：“电回来了，站长说‘剩下的交给你了’——挺好。可我马上又要钻回那间每次进门都吸我 10 格氧气的冷屋子，而我的氧气还剩多少，依然是个谜。”

- 死亡结算时："我不明白。提示说'别忘了拿补给'——可我明明拿了三处补给。到底还差多少？游戏从头到尾没告诉过我一个字。"

## 人设② 爱吐槽的老玩家 · 林小晨
结局：🏁 **结局 B · 取舍**——站保住了，桑尼跑了。
> `桑尼钻进逃生舱。尾焰亮了一下，那小星很快就滑进了木星的阴影里——只留下一句"下次见"。站保住了，人也全都安全——只是，账还没算完。`

### 场景首入：我想干什么、能不能干（要点）
- 开局：先看商店——"有货没买法，先猜命令"。猜着敲 `buy` 买下电池（"5 枚"到底是数量还是价钱？）。
- 医务室：**发现新分支**——因为还没拿到保险柜密码，多出"问阿雅：密码谁会知道？"，阿雅指路"糖糖都记在芯里"（好设计）。
- 健身房："请他开门"是灰的，注释写"得先有个由头——去实验室找老布聊聊"——**这条提示是可执行的**（好），比实验室那个"知道走法的你"强太多。
- 维修区：用 🔦 手电拖出老布的红漆工具箱——**老布亲自溜下来送芯片**（"拿去，轻点儿放。"）。这条线比"自己开柜"少花 10 点氧气（人设①不知道，走了冤枉路）。
- 仓库：门禁解锁后直接硬拿冷却剂——桑尼翻脸放无人机（本局没走猫线，对质选项全程是灰的）。
- 结局对峙：`1) 🔒 揭发他…（灰：（手头得有能摆上台面的东西。））` 是灰的——因为本局没走猫线、没有账本；`3) ⚔ 拦住他的无人机。　你的武力值 5 < 6`——全副武装**就差 1 点**，差在哪从头到尾没说明。于是选择"放他走"，拿到结局 B。
- 其余首入一句话：睡眠舱——翻自己的柜子拿补给（+10），柜门卡得死紧的细节我喜欢；气闸舱/站外——出舱一次 -20，场景写着“每次出舱 -15”却从不写“还剩多少”；太阳能控制室——推闸复电干脆利落，这段没毛病。

### 每 10 步 · 当下心里话（原话）
- 第 10 步："商店摆货不给买法，'5 枚'连单位都不写；铁头那个'得先让他服气'——怎么服？你倒是说啊。好游戏该在选项里告诉我怎么做，不是让我猜谜。"
- 第 20 步："工具箱线才是正道——老布把芯片塞我手里的时候像个真人。可这游戏的'难度'全是纸糊的：门禁一句'提我'就开，急救箱'搭把手'就下来；真正卡人的全是没告诉我规则的地方。"
- 第 30 步："授权卡是站长亲手给的，挺暖。但我到现在都不知道'武力值'到底怎么算——它默默从 0 涨到 5，我还是从失败预览里反推出来的。"
- 第 40 步：“全站复电——下一步就该点反应堆了。可到现在我还是不知道武力值怎么算、氧气还剩多少：这游戏里我唯一学会的事，就是别信任何一个没写规则的数字。”
- 对峙时："全副武装 5 < 6。差 1 点，差在哪？你不说我永远不知道。行，放他走，我不跟黑箱赌。"

## 人设③ 带娃家长 · 林小晨
结局：🏁 **结局 A · 圆满**——真凶落网、全员平安。
> `你把账本摊在铁头面前——「猫粮」进、「矿石」出，一笔一笔，全对得上。桑尼的笑容，一点点垮了下去。铐子"咔"地扣上。广播里，站长的声音很稳："反应堆稳定，全员安全。林小晨，谢谢你。"—— 晨星号，重新亮起来了。`

### 场景首入：我想干什么、能不能干（要点）
- 开局：**先给结论**——全黑+漏气的开场对小孩偏吓人，但胖胖一句"别慌别慌——先别动，汤还热着呢！"把气氛救回来了；"洗碗挣星币"在逃命时刻出现，孩子会问"为什么要洗碗？"
- 观景厅：**全线最惊喜**——"站猫银河"（"只吃真鱼，对合成粮闻都不闻"）→ 用鱼罐头换回它从仓库顺出来的「货运登记」账本 → 铁证到手。（全流程无血腥、无暴力，适合带孩子看。）
- 维修区：小帮手一眼"认准了你"（"它决定跟着你了"）——孩子会喜欢；但旁边的 ⚔/武力值 战斗逻辑完全没有给小孩解释。
- 健身房：**掰手腕赢了**（`⚔ 你赢了！`），但代价 -5 氧气，奖励和"直接求助"一模一样——赢了也亏，纯粹是我自己头铁。
- 应急逃生舱：发现**撤离路线**（检查三枚逃生舱 → 得到钥匙与“逃生舱检查过”线索；发射键仍灰：`（逃生舱要检查好，大家也要喊齐——缺一样，按下去都不算全员撤离。）`）。“喊齐”指向通讯舱的**全站广播**按钮（人设① 的发现）——没按（怕吓到人）。
- 结局对峙：`1) 揭发他：把证据亮给铁头看。`（账本在手，解禁）、`3) ⚔ 拦住他的无人机。　你的武力值 6 ≥ 6`（应急盾刚好补上第 6 点）。我选了**不流血的揭发**。
- 家长备注（会不会学坏）：电击棒/无人机/铐子的出场都点到为止；**封口费选项**（"接过他递来的'封口费'……这份好处迟早要还"）和收贿死雷属已知在案，不重复计数，但建议保留给家长可见的明确定位提示。
- 其余首入一句话：睡眠舱——应急包一口气 +10（手电/工牌/氧气瓶）；中央大厅（中层）——路过补给柜被“无声投喂” +5，孩子会问“谁给我的”；反应堆舱——场景写了“每次进入 −10 点氧气”（这点好），但剩余量看不见。

### 每 10 步 · 当下心里话（原话）
- 第 10 步："账本到手了，我竟然是用一罐鱼罐头换的——这设计真可爱。可它明明白白写着'猫粮进、矿石出'，孩子也能看懂这是做坏事；这部分我很满意。"
- 第 20 步："芯片是老布亲手送的，比人设①那条冷冰冰的'撬柜子'路线好太多。同一个目标两条路，一条暖一条冷——如果孩子先走了冷的那条，会以为这游戏没人情味。"
- 第 30 步："医务室里站长醒来说的第一句话是'反应堆……'，然后才是谢谢我——这个人物立住了。孩子会记住'先顾大家'这四个字。"
- 第 40 步："出舱一次 20 格氧气，我全程不知道还剩多少。连我一个大人都心慌，小孩坐旁边看会更焦虑——建议给氧气配一个看得见的格子。"
- 第 50 步："赢了对峙：不用打，把账本摊开就行。这个结局我愿意给孩子看。"

## 四类"怪"（各 ≥2 条，全部引 CLI 原文）

### 类① 我不该知道这个
**①-1｜商店先于一切出现**（人设①②③，食堂·开局第一屏）
- 节点/操作：新局首屏。
- 我原话：`🛒 商店：🍱 合成料理 5 枚、🔋 备用电池 5 枚`
- 为什么怪：我还不知道"星币"是什么、从哪来，不知道料理/电池有什么用，商店就先摆好了；"5 枚"是数量还是价钱也要猜（后来才确认是价钱）。
- 严重度：笑笑就过。

**①-2｜"那只猫"与"账本"凭空被点名**（人设②，仓库）
- 节点/操作：首次进仓库看选项。
- 我原话：`2) 🔒 把账本拍在他面前。　（灰：（手头还没有能让他变脸的东西——先想想那只老往仓库跑的猫。））`
- 为什么怪：本局此前从没人提过任何猫、任何"账本"；注释用"**那只**猫"这种既定指称跟我说话，选项名还把"账本"这个我尚未发现的物品直接写出来——等于剧透。
- 严重度：皱眉。

**①-3｜机器人张口就给站长保险柜密码**（人设①，糖糖带路）
- 节点/操作：在指挥舱选"问它：你能带我去哪儿？"
- 我原话：`"还有——站长室的保险柜，密码 0325，是我帮站长设的；柜子里锁着一张备用的站长授权卡，是站长留的后手。"`
- 为什么怪：我只问了一句"你能带我去哪儿"，第一次见面的机器人就把站长级秘密全盘托出，我什么都没做就"知道"了。
- 严重度：笑笑就过（玩着方便，但"知道得没道理"）。

### 类② 我为什么要做这个
**②-1｜逃命时刻的"打工"选项**（人设①，食堂/实验室）
- 节点/操作：开局选 `3) 留下来帮胖胖洗碗。（挣几个星币，就是要费点力气。）`；实验室同款 `3) 给老布打下手。（挣两个星币，就是要费点力气。）`
- 我原话："空气在漏、站长昏迷，为什么我要洗碗？而且星币能干嘛当时完全不知道——我洗了三碗花掉 15 点氧气，商店还是买不了。"
- 为什么怪：动机与场景冲突；奖励（星币）在当时不可用也不解释用途，白扣氧气。
- 严重度：皱眉。

**②-2｜掰手腕：赢了也白赢**（人设③，健身房）
- 节点/操作：选 `1) ⚔ 跟他掰手腕。（力气活——费力气，也费氧气。）`
- 我原话：`· -5 点氧气` → `⚔ 你赢了！（武力值 4 ≥ 1）` → 获得机械手套、门禁解开——**与人设②"直接请他开门"（0 氧气）的结果完全相同**。
- 为什么怪：我主动花氧气换了个"面子"，奖励毫无差异，等于惩罚主动玩家。
- 严重度：皱眉。

**②-3｜"老布的委托"悬空不消失**（人设①）
- 节点/操作：先拿到控制芯片，再回去看老布。
- 我原话：老布原地重播 `"我的宝贝工具箱不见了！……芯片的事，免谈！"`；选项里的"帮他去找工具箱"消失，但线索栏里的 `老布的委托` 永远挂着。
- 为什么怪：任务窗口静默关闭，玩家既没完成也没收到取消提示，线索栏变成"死任务"陈列柜。
- 严重度：皱眉。

### 类③ 做了没反应
**③-1｜查货单可以无限复点**（人设①，通讯舱）
- 节点/操作：连点两次 `2) 查一查被改过的货单。`
- 我原话（两次输出逐字相同）：`💬 货单上「猫粮」那一栏被人改成了「矿石」——字迹很急，改得歪歪扭扭。为什么是矿石？你把它记在心里。`
- 为什么怪：文案说"你把它记在心里"，但线索栏没有这条、选项也不消失、复点无任何变化——到底记没记住？
- 严重度：皱眉。

**③-2｜老布对芯片视而不见**（人设①，实验室）
- 节点/操作：带着 `💠 控制芯片` 再进实验室。
- 我原话：老布台词一字不差重播（含"**芯片的事，免谈！**"）——我手里正握着芯片。
- 为什么怪：NPC 不识别玩家已持有的关键物品，世界不认我的战果。
- 严重度：皱眉。

**③-3｜复电后世界不认账**（人设①，多场景）
- 节点/操作：全站复电后回访。
- 我原话：复电后回访：食堂仍是 `灯“啪”地全灭了。黑暗里……空气正在漏走（氧气 −5）。`（实际不扣氧，log 无事件）；糖糖仍是 `“还有，得先把电力找回来！”`（那时我的芯片、冷却剂、授权卡都已凑齐）。
- 为什么怪：全站最大的事件（复电）对场景文案与 NPC 零影响，玩家刚做的事像没发生过。
- 严重度：皱眉。

### 类④ 像被系统当傻子
**④-1｜氧气是全黑箱，死亡无预警**（人设①）
- 节点/操作：全程；致死点=第二次进反应堆舱。
- 我原话：余额还有 50 时，状态栏只写 `💨 氧气 还好`；等它第一次换档（`有点闷`）时余额已掉到 30、第二次（`快喘不上气`）是 20——全程不给数字；再进反应堆舱 `-10 点氧气` → `💀 氧气耗尽——闯关失败！`
- 为什么怪：关键资源只有三档模糊形容词、没有数字；玩家无法规划、无法知道"还能撑几步"；死点恰好在终点线前一步。经复盘（依据 log 台账与档位切换点推导）：容量=100，本局支出 120、补给 20，净 -100 归零。
- 严重度：**关掉游戏级**。

**④-2｜商店/回收只有展示、没有入口**（人设①②③）
- 节点/操作：食堂商店与维修区废料回收斗。
- 我原话：`🛒 商店：🍱 合成料理 5 枚、🔋 备用电池 5 枚`（无购买动作）；`♻ 废料回收：⚡ 电击棒、🧤 机械手套、🔦 手电……`（无卖出动作）；而任务灰注释明说 `（灰：（翻遍口袋——没有能用的电池。食堂那台旧贩卖机里，有卖。））`。`buy`/`sell` 命令只存在于 `help` 输出里（"buy <编号|道具名> 在商店买东西"）。
- 为什么怪：游戏点名指向"食堂有卖"，但玩家侧界面从头到尾不给任何购买入口；星币挣了、花了、被偷了，唯一被承诺的花钱方式不存在于可见操作。真人不会去猜隐藏命令——**直接卡死**。
- 严重度：**关掉游戏级**（卡关型）。

**④-3｜“武力值”黑箱 + 无预告惩罚**（人设①②）
- 节点/操作：维修区选 `1) ⚔ 把卡住的机器人从货架底下拖出来。　你的武力值 0 < 1`
- 我原话（人设①）：`· -5 点氧气` → `· ⚔ 你输了……（武力值 0 < 1）`。此后它随装备无声地变化：① 见过 0→3→4；② 见过 1，并在对峙处撞上 `你的武力值 5 < 6`——它的构成、还差几点、怎么涨，全程无说明。
- 为什么怪：核心战斗数值从不解释——只在具体对抗的选项行里出现对照（如 `你的武力值 0 < 1`），但它的构成、怎么涨、还差几点全靠猜；失败后果（扣氧）未预告。
- 严重度：皱眉（多次遭遇会升级为关掉游戏）。

**④-4｜灰选项自相矛盾，且只有机器报错**（人设①）
- 节点/操作：实验室选灰选项。
- 我原话：`2) 🔒 （知道爬道走法的你）打开工具柜，自己动手。　（灰：（得先摸清爬道怎么走。））`——糖糖**刚刚**才把走法教完；点它得到 `✗ 选项 2「（知道爬道走法的你）打开工具柜，自己动手。」现在不能执行：（得先摸清爬道怎么走。）；（位置没有变化）`，没有任何剧情反馈。后来证实：只有**亲身爬过一次**（-10 氧气）才算"知道"。
- 为什么怪：选项标题与门槛自相矛盾（说我知道，又说我得先去知道）；口头教学不算数、也无提示；失败反馈是冰冷的机器句式。（置灰议题本身在案；本条为"状态与文案互相打架"的事实矛盾。）
- 严重度：皱眉。

**④-5｜`read` 用法行是错的，照抄被冤枉**（人设①）
- 节点/操作：翻看 `📝 站长的便条`（`items` 明确标着 `📖 可读`）。
- 我原话：游戏自打印 `✗ 用法：node tools/play.mjs read <道具名>（手里能翻看的：站长的便条）`；照抄执行 → `✗ 你手里没有「站长的便条」这件东西，翻看不了；（没有变化）`（连在手的 `控制芯片` 也这错）；加 `--player` 前缀才成功。
- 为什么怪：系统给的说明和实现不一致；玩家照做却被系统反咬"你没有这东西"。
- 严重度：皱眉。

## 最影响体验的 3 条（按"会不会关掉游戏"排序）
1. **氧气黑箱与无预警猝死**（④-1，人设①）：看不见的资源 + 死在终点前一步。关掉游戏的直接诱因——"我死得不明不白"。
2. **商店/贩卖机有货无入口**（④-2，三人设共通）：任务亲口说"食堂那台旧贩卖机里，有卖"，玩家却找不到任何"买"的动作；`buy/sell` 只藏在 `help` 里。真人在此卡关或放弃。
3. **“武力值”黑箱与无预告惩罚**（④-3，人设①②）：从不解释的核心数值 + 判负才现身 + 扣氧无预告；单次是皱眉，多次即是“这游戏不想让我懂”。

## 一句话结论
故事、角色与道具都很可爱（老布送芯片、猫换账本、全员撤离的备选结局），但**氧气、星币、武力值这三个核心系统全部是不透明黑箱**——真人玩家的挫败几乎都来自"我不知道规则"，而不是"游戏太难"；把这三只黑箱换成看得见的数字与入口，这款游戏的真人体验会立刻从"猜谜"变成"冒险"。
