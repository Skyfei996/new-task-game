## 2. 世界观与角色

**设定**：星历 2187 年，木星轨道的补给中继站「晨星号」（环形三层结构：外层生活区 / 中层工作区 / 内层核心区）。你是趁暑假来参观的**实习生**——站上最小的乘员，编号 09，名叫**林小晨**（大家都叫你小晨；开场可以改成你自己的名字）。

**基调**：冒险 + 搞笑。合成料理难吃到出名、维修机器人有性格、站长养了一只不吃合成粮的站猫。

## 3. 剧情大纲（三幕 + 3 结局）

**开场**：你到站第一天，参观到一半——全站断电、警报响起、**氧气开始减少**。

- **第一幕·摸黑求生**（0~30%）：找到手电/工牌/氧气瓶，认识乘员；发现主供电是**被人为拔掉的**——不是事故。
- **第二幕·重启反应堆**（30~70%）：重启需要三件事，各有两条以上路径（防卡死）：
  - 控制芯片：① 老布给（帮他找零件）② 糖糖带你走维修爬道去实验室自己拿
  - 冷却剂：仓库（桑尼阻挠）→ ① 铁头开门硬拿 ② 用站猫罐头收买他的猫/或用账本把柄
  - 站长授权卡：① 医务室找阿雅（站长受伤被救）② 气闸舱（站长被困）
- **第三幕·真相与选择**（70~100%）：证据 + 授权到位后面对桑尼——
  - 结局 A **圆满**：重启反应堆 + 揭发桑尼 + 全员安全（需要证据 + 资源充足）
  - 结局 B **取舍**：反应堆重启成功，但桑尼乘救生舱跑了（证据不足/耽搁太久）
  - 结局 C **撤离**：反应堆来不及修，你带全员进救生舱撤离（全员生还，站放弃）——前置：检查过逃生舱 + 已广播集合（§8.5）
- **失败**：氧气 ≤ 0（"眼前一黑……"，44 号结算）；**星币不再判失败**（花光只到 0，不结算）；剧情性失败保留 29 号（收封口费后再进反应堆舱被桑尼埋伏）。

## 8. 体验层整改（v2 · 2026-10-01）

> 来源：`station-rework-v1.md`（老板已批准）＋ `playtest-01-report.md`（P1~P12）。本文给"改到什么程度"的定值；逐句文案与提示分级见 `design-station-nodes.md` §8。

### 8.1 星币经济：断循环

**现状（bug）**：洗碗 +2 星币/−5 氧、料理 3 星币→+10 氧 ⇒ 每 3 星币净赚 +2.5 氧，可无限刷（证据 `station.js:172-173`）。

**改法（提价方案）**：

- 料理 **3 → 5 星币**；重复劳动的氧/星币汇率统一 2.5（洗碗 +2/−5；老布打下手 +3→**+2**/−5）；
- 自动贩卖机（食堂）货架：合成料理 5 星币、**备用电池 5 星币**（星币的"工具"等价物；中层大厅不再送电池，只留氧气 +5）；
- 星币可花到 0、花光不判失败（`coins.fail: null`，移除 `noSpendToZero`）。

**算式**：劳动 1 星币成本 = 5/2 = **2.5 氧**；料理 1 星币产出 = 10/5 = **2.0 氧** ⇒ 2.0 < 2.5，循环必亏。
一轮"洗碗×3 → 买 1 盒 → 吃掉"= −15 + 10 = **净 −5 氧**；断言 20 轮 = **−100 ≤ 0** ✓。

**不做**（另两个方案）：料理限量（20 轮断言失去意义、星币失去等价物）；料理不回氧（料理变死物）。洗碗软上限也不加（换钱是防卡死兜底，与料理侧无关）。

**失败与 45 号**：星币侧不再有失败结算；45 号编号**改为保险柜事件节点**（R10 的反馈落点，保住 45 点网络计数）。剧情性失败保留 29 号（收封口费后再进反应堆舱被桑尼埋伏）。

### 8.3 提示分级（hint）与灰显措辞

- **三档**：`vague`（缺省，感官/力气式暗示，不给结果）、`none`（纯动作或纯移动，不给暗示）、`exact`（写明效果——白名单制）。
- **exact 白名单**（仅此三类）：① 商店明码（价格与货架）；② 已知道具的使用（例："吃一盒合成料理（+10 氧气）"；本作含 1 号④、20 号两处）；③ 战斗规则显示（"你的武力值 X ≥/< Y"——沿用示例关的透明决策，且让孩子敢打）。**③ 为白名单新增项**（R06/S3 原文只写"商店与已知道具"），待老板确认（见批次档 B01 §2 修正轮 1）。
- **引擎不自动附加**：选项上不自动出现"（获得 X）（−N 氧）"或效果数值；写什么由作者定，白名单外的选项一律 vague/none。
- **灰显措辞**：每条锁定项用 `lockText` 写玩家向理由——不含数字、不用"条件/线索/状态"等内部词；写"缺什么/还不到时候"。
- **走查口径与结论**（逐条对照见 `design-station-nodes.md` §8）：
  - 分母 = 全关**动作选项**（不含纯移动/返回/电梯、商店与回收明码块；40 号终局分叉键单列）。
  - 判定（满足其一即计）：**代价** = 点击消耗/交出资源或道具；**风险** = 战斗/陷阱/可损失；**不确定** = 拿到什么、或会被带到什么结果，不写在文案上。
  - 清点：动作选项 41 条；例外（写明结果且无代价/风险）9 条——4②、8②、12②、13②、14②、16③、17②、17③、19① ⇒ **32/41 ≈ 78% ≥ 70%** ✓。（原清单里的“12③”按 §5 节点表口径是“回底层大厅”纯移动项，与分母口径相抵，已剔除。）
  - 主线选项"直接剧透产出" = 0 条；精确提示只出现在白名单三类（③ 为新增项，待老板确认）。
- **--player 玩家模式口径**（给体验师）：隐藏资源数字（改定性档位：氧气 ≥50%"还好"、20~50%"有点闷"、<20%"快喘不上气"；星币 ≥5"能买点东西"、1~4"不多了"、0"花光了"）、武力面板、步数与计数、去向编号、机械理由；显示 lockText。**例外**：战斗选项保留与真实玩家一致的「你的武力值 X ≥/< Y」（白名单③；与网页版渲染一致）。
- **去向标注**：引擎的"→ 编号 / 节点名"标签从**玩家视图**（网页 + `--player`）撤下——它会把事件节点的名字直接剧透（例："→ 22 黑暗中的动静"）；导航由地图高亮（网页）与选项里的方向感文案（R09）承担。lab 与开发版 CLI 保留该标签。
