## 2. 世界观与角色

**设定**：星历 2187 年，木星轨道的补给中继站「晨星号」（环形三层结构：外层生活区 / 中层工作区 / 内层核心区）。你是趁暑假来参观的**实习生**——站上最小的乘员，编号 09，名叫**林小晨**（大家都叫你小晨；开场可以改成你自己的名字）。

**基调**：冒险 + 搞笑。合成料理难吃到出名、维修机器人有性格、站长养了一只不吃合成粮的站猫。

**8 位乘员（人物卡，沿用现有画像+光环系统）**

| # | 人物 | 身份 | 性格/作用 |
|---|---|---|---|
| 1 | 站长 伊莲娜 | 站长 | 铁面但护短；停摆后**失踪**——找到她是主线关键 |
| 2 | 总工程师 老布 | 工程师 | 零件控老头，说话绕圈子；能修一切，但要"配套零件" |
| 3 | 医官 阿雅 | 医生 | 冷静姐姐；医务室有药品与氧气瓶 |
| 4 | 厨师 胖胖 | 食堂主厨 | 快乐胖子；买食物/收购废料（经济循环的关键） |
| 5 | **R2-糖糖** | 实习维修机器人 | 你的伙伴；知道站里的每个角落（**线索主要来源**） |
| 6 | 安保队长 铁头 | 安保 | 肌肉正直，能开安全门；被桑尼骗得团团转 |
| 7 | 货运主管 桑尼 | 仓库主管 | 笑眯眯，**真凶**：偷运星尘矿石，断电是为掩护 |
| 8 | 站猫 银河 | 猫 | 搞笑担当 + 关键线索（总出现在"出事"的地方） |

## 3. 剧情大纲（三幕 + 3 结局）

**开场**：你到站第一天，参观到一半——全站断电、警报响起、**氧气开始减少**。

- **第一幕·摸黑求生**（0~30%）：找到手电/工牌/氧气瓶，认识乘员；发现主供电是**被人为拔掉的**——不是事故。
- **第二幕·重启反应堆**（30~70%）：重启需要三件事，各有两条以上路径（防卡死）：
  - 控制芯片：① 老布给（帮他找零件）② 糖糖带你走维修爬道去实验室自己拿
  - 冷却剂：仓库（桑尼阻挠）→ ① 铁头开门硬拿 ② 用站猫罐头收买他的猫/或用账本把柄
  - 站长授权卡：① 医务室找阿雅（站长受伤被救）② 气闸舱（站长被困）
- **第三幕·真相与选择**（70~100%）：证据 + 授权到位后面对桑尼——
  - 结局 A **圆满**：重启反应堆 + 揭发桑尼 + 全员安全（需要证据 + 资源充足）
  - 结局 B **取舍**：反应堆重启成功，但桑尼乘救生舱跑了（证据不足/耽搁太久）
  - 结局 C **撤离**：反应堆来不及修，你带全员进救生舱撤离（全员生还，站放弃）
- **失败**：氧气 ≤ 0（"你眼前发黑……"）；信用点 ≤ 0（"你的账户被冻结，寸步难行"）——两种失败都有明确结算与重开。

## 5. 道具、经济与战斗

**道具（约 18 件）**：手电、工牌、氧气瓶、万能扳手、磁力靴、焊接枪、控制芯片、冷却剂、授权卡、备用电池、医疗包、绳索、站猫罐头、合成料理、桑尼的账本（证据）、逃生舱钥匙…
**武力装备（3~4 件）**：焊接枪（+1）、电击棒（+2）、机械手套（+1）、应急盾（+1）——对手：失控维修机器人（1）、安保机器人（3）、桑尼的无人机（6）
**线索（知识解锁）**：维修代码、反应堆安全规程、桑尼的走私暗号
**经济**：信用点（自动贩卖机/食堂消费；赚钱＝帮厨、回收站卖废料、给老布当学徒）——**可循环**（防卡死第 3 条）
**失败条件**：氧气 ≤0 / 信用点 ≤0（每关可配置，见引擎需求）

## 6. 防卡死设计（老板点名要求 —— 硬规则）

| # | 规则 | 说明 |
|---|---|---|
| 1 | 关键道具**不可消耗、不可出售、不可丢失** | 沿用"红框"机制 |
| 2 | 每个门槛**至少两条解法** | 三件重启物的路径已按此设计（§3） |
| 3 | 经济**可循环** | 赚钱途径不枯竭；氧气有免费补给点（≥2 处） |
| 4 | 失败条件**始终可达** | 真卡住时，资源耗尽会自然走向失败结算（不会"永远挂着"） |
| 5 | 引擎兜底**走投无路检测** | 当前节点无可执行选项、无可达编号、无可用资源 → 弹"求救面板"（回到安全屋 / 重开本关） |

## 7. 本作需要的引擎能力（v0.2，实现时再拆技术方案）

1. **多关卡架构 + 关卡选择页**：启动页列出关卡（含《勇闯大里姆》），每关独立数据/素材/存档
2. **可配置资源与失败条件**：资源表（名称/图标/初始值/失败规则）+ 失败结算文案（本作＝信用点 + 氧气）
3. **走投无路检测与兜底出口**（§6 第 5 条）
4. **玩家名**：开场（选难度页）输入框（默认「林小晨」），姓名存进存档；任务点文本支持占位符 `{me}`，渲染时替换成玩家名（乘员对话里用）
5. （后续里程碑）音效与音乐钩子
6. **多场景共用点**：同一编号点出现在多个场景的 pins（如电梯井）→ 该点无固定区域、保持当前场景（`sceneOfNode` 遇多点命中则返回 null）；场景切换沿用 v1.2 的机制（跨区目标缀区域名 + 气泡 + 角标）
