## 一、先看懂原书：这一关是怎么设计的

以《勇闯大里姆》为例，原书根本不是"翻到哪页读哪页"的选择题册，而是一个**儿童版迷你开放世界 RPG**。它由 8 个系统咬合而成：

| # | 系统 | 原书做法 |
|---|------|----------|
| 1 | **任务点网络** | 共 57 个任务点：1~35 是地点类任务点（其中 1~30 在两张场景图上印有编号，31~35 图上无编号点），36~57 是事件/结局节点。走法呈网状——同一目标往往有多条路（例如通往结局的就有鹦鹉、机器人、韦伯女儿三条剧情线）。 |
| 2 | **货币经济** | "萨瓦币"贯穿全程：开局 15 枚（普通）/10 枚（困难）；花在购物、贿赂、补票上；被扒手偷（大厅每次 −1、牢房 −2）；从事件奖励和出售道具中赚。**花钱本身就是抉择**。 |
| 3 | **背包与道具门槛** | 22 件道具。大量选择题用"如果你有 X"分流；道具会被消耗或送人（汉堡包给流浪汉、毛绒玩具给小姑娘、泻药下到咖啡里……）；红框道具不能卖。 |
| 4 | **武力值战斗** | 5 件道具提供武力加成（+1/+1/+2/+3/+1，满配 8）。敌人武力值：猫 1、拉克洛 2、马克斯 3（被下药变 1）、保镖 6。**打赢 = 打开新分支，打输 = 直接失败**。 |
| 5 | **秘密知识** ★ | 全书最妙的设计：**信息本身是道具**。"电梯密码 956"（贝泽福告诉你）→ 你在取款机旁可以乘电梯直达 56 号；"魔法数字 32"（入侵电脑发现）→ 你在游戏城抽奖可以**直接中奖**。信息不花一分钱，但改变一切。 |
| 6 | **随机与自查** | 抽奖后"偶数/奇数"分流，接着要**数自己背包里的道具数 / 萨瓦币数**判奇偶来决定中奖——把"清点自己的物品"变成玩法。 |
| 7 | **失败与结局** | 39/50 = 闯关失败；57 = 闯关成功；40/41/49 三条不同剧情都能通向 57。失败不惩罚性没收进度，鼓励重试换路。 |
| 8 | **场景上的编号与起点** | 编号直接印在画面里，另有"起点"箭头。数字是"空间导航"的锚点。 |

**一句话总结原书的设计 DNA：开放探索 + 经济取舍 + 收集/战斗门槛 + 知识解锁 + 多线结局。**

## 二、怎么搬成网页游戏

### 2.1 核心思路：引擎与内容分离

图只是"皮肤"，游戏本体是**数据驱动的状态机**。同一套引擎，以后所有关卡（包括原创）都只是换一份数据。

```
场景图 + 编号坐标(pins)  ┐
事件/选项/条件/效果       ├──►  一个通用引擎  ──►  网页游戏
道具表 + 货币 + 线索      ┘
```

### 2.2 数据结构（已实现，见 `prototype/levels/dalim.js`）

- **scenes**（场景表，v1.2）：每张背景图一条——图片路径、原图尺寸、编号坐标 `pins`（存"原图像素坐标"，显示缩放时自动换算——屏幕大小、手机/电脑永远不会错位）。当前两个场景：`market`（一楼，官方 800px 图，16 个编号）与 `basement`（负一层，实体书照片透视纠偏版 1600×1132，14 个编号）
- **nodes**（任务点）：`n` 名称、`t` 正文、`c` 选项列表、`en` 进入时效果（只触发一次/每次触发）、`shop`/`sell`/`fail`/`win` 特殊类型、`chars` 关联人物（v1.3）
- **characters**（人物表，v1.3）：`name` 名称、`title` 称号、`img` 画像（`images/chars/*.jpg`，从书页照片裁出）、`bio` 书上的介绍原文、`spot` 所在位置（`scene` 场景 id + 该图原图像素坐标）；`charOrder` 决定图鉴顺序。任务点用 `chars` 关联——触发时地图上高亮该人物 + 侧栏出现「本处人物」小卡
- **选项**：`cond` 条件（有道具/没道具/金币足够/知道线索/任一道具/未全访问）、`fx` 效果（获得/失去/加减币/学线索）、`battle` 战斗、`random` 随机、`back` 返回、`prices` 价格选择
- **状态**：金币、背包、已访问、已触发、已知线索、腕带价格、当前区域 `scene`（v1.2）、历史栈（供“返回上一个任务点”）

### 2.3 关键映射决策

| 原书 | 网页实现 |
|------|----------|
| 抽奖"可能是偶数也可能是奇数" | 50/50 随机（原书判定规则待核对，见 §五） |
| "前往上一个任务点"（45/48 号） | 历史栈返回按钮 |
| 战斗"总武力值 ≥ 对方" | 即时计算，按钮上直接显示"你的武力值 X ≥/< 对方 Y" |
| "如果你有 X"的选择题 | 分两类：**诱惑型**（灰显🔒+"需要 X"，让孩子知道"还有这条路"）和**互斥型**（只显示当前可行的那条，与原书一致） |
| 战斗胜利后的"任选去处" | 增加 3 个辅助节点（3W/8W/29W），不进"已探索"列表，纯粹做战中转 |
| 铅笔打钩/擦记号 | 全部自动化：背包、金币实时结算 + 气泡提示 |

### 2.4 界面设计（见原型）

```
┌──────────────────────────────┬────────────────────┐
│                              │ 🪙15  ⚔1  🎒 ❓ ↺   │
│      场景图（可拖拽缩放）      │ 已探索：⑤ ⑦ ⑪ …     │
│   ・编号环（已访问=绿，当前=脉动）│ ┌────────────────┐ │
│                              │ │ ⑤ 武器专卖店      │ │
│                              │ │ 正文……           │ │
│                              │ │ [选项按钮]       │ │
│                              │ │ [🔒 灰显选项]    │ │
└──────────────────────────────┴────────────────────┘
```

- **编号环 + 灰暗遮罩**：整张场景图罩一层灰暗滤镜，只在“当前位置 + 下一步可达的位置”开灯；只有可达编号可以点击（点击 = 执行对应选项，含条件与花费）。已访问的编号淡绿色显示；重开、换图只需改 `pins` 坐标
- **当前位置更醒目（v1.3）**：当前位置用青蓝大光环 + 呼吸动画 + “你在这里”小标签；“可去”的位置保持黄色、略小——两者一眼可辨
- **选项 ↔ 地图对应**：每个选项按钮标注将前往的编号（如 `→ 33`；战斗标注 `胜 → … ｜ 负 → 39`；返回类标 `↩ 返回`）；鼠标悬停选项时，地图上对应点会闪亮
- **区域切换（v1.2）**：两张背景图——一楼（`market`）与负一层（`basement`）。走到负一层的编号点自动切换到负一层图，回到一楼再切回来；"节点属于哪个区域"由它印在哪张图上决定（单一数据源），无编号的事件节点（36~57 等）保持当前背景图。选项通往另一区域时，目标编号后标注区域名（如 `→ 4（负一层）`）；切换瞬间有气泡提示，场景左上角常驻当前区域角标
- **背包**：完整 22 格清单（未获得灰显、武力加成标注、红框标"不可卖"）——对应原书的"你的背包"打钩页
- **商店/出售/取款**：就地操作，价格与库存由数据驱动
- **提示气泡**：得币/失币/获得/失去/学到线索都有即时反馈；**被偷时（v1.3）**：侧栏顶部大号警示条（红=被偷，如「🥷 戈高偷走了你 1 枚萨瓦币！」；有防盗绳时绿=「🪢 防盗绳挡住了戈高」）+ 金币计数红闪 + 飘出的「−1」。主动付款（行贿/罚款/抽奖）玩家自己知情，不弹条——但它们同样受「金钱 ≤ 0 判失败」约束
- **人物高亮与人物卡（v1.3）**：走到点名人物的任务点（如 28 号→戈高、8 号→克斯托），地图上该人物所在处亮起光环 + 名字标签（不挡编号点击）；侧栏「👤 本处人物」小卡点开看画像与介绍；另有「👥 人物图鉴」可随时翻看 8 张人物卡
- **存档**：浏览器本地自动存档，重开自动续
- **校准模式**（键盘 `C`）：点击画面任意位置显示坐标——用于精修编号位置

### 2.5 与原书的有意差异

1. **移动方式（v1.1 据试玩反馈修改）**：跟随条目行走——地图只点亮“当前位置 + 下一步可达”，且只有这些点可点击；已探索列表仅作进度展示。原因：自由跳点会绕过剧情门槛（例如空手直闯警卫室/电梯口），也失去“从门口一步步走进去”的空间感。引擎留有 `FREE_MOVE` 开关（默认关）。
2. **条件透明化**：灰显的🔒选项让孩子看到"世界上还有别的路"；原书很多路径要自己发现。可切回隐藏模式。
3. 数字版补足：自动存档、重开、失败无惩罚重试。
4. **货币底线（v1.3，老板裁定）**：钱不会变负数（最少 0）；**金钱 ≤ 0 直接判闯关失败**（被偷光/花光都算）；**买东西不允许花到 0**——付款后必须至少留 1 枚，否则不可点（防手滑把路走死）。

### 2.6 关卡衔接与跨关道具（v1.3）

本关（勇闯大里姆）通关后，玩家获得**韦伯的机器人工厂的平面图**（实体书通关页照片：`images/1.jpg`），即下一关「机器人工厂」的入场线索；原型通关界面会点出这条奖励。

跨关模板（未来原创关卡沿用）：每关设计时明确两件道具——**入场道具**（上一关通关时交给玩家的东西，本关用它开门）与**通关道具**（本关结束时交给下一关的东西）。
