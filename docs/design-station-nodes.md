## 1. 关卡目标与两条主线

- **总目标**：重启反应堆 → 揪出搞鬼的人。
- **重启需要三件东西**（各有两条以上拿法，防卡死）：

- **线索**：保险柜密码（23 / 35）、维修爬道路线（16 爬道）、已广播集合（8）……
- **消耗品**：站猫罐头（哄银河换账本）、合成料理（+10 氧）、医疗包（给阿雅救站长）、备用电池（修机器人用）

## 4. 氧气（唯一失败资源）

- 开局：普通 100 / **困难 30**；HUD 常驻显示。
- **支出（每层都有）**：顶层 −25 ｜ 中层 −10 ｜ 底层 −40 ｜ 站外 −20（主线账面口径；逐段明细与预算表见 `design-station-v1.md` §8.2）。
- **补给（每处一次；毛额口径）**：睡眠舱氧气瓶 **+15**（翻找 −5 ⇒ 净 +10）、医务室氧气站 **+10**（搬运 −5 ⇒ 净 +5）、中层大厅补给柜 **+5**；热食：观景厅料理 +10、贩卖机料理 +10/盒（普通最多 4 盒 / 困难 3 盒）。**可得合计**：普通 100 + (15+10+5) + (10+40) = **180**；困难 30 + (15+10+5) + (10+30) = **100**（逐段表见 `design-station-v1.md` §8.2）。
- **失败**：氧 ≤ 0 → 44 号结算「眼前一黑……」。
- **验算结论**：普通结余 47.2%（≥30%）；困难结余 5.00%（≤5%）——困难必须拿满补给 + 吃掉热食 + 走主线。

## 6. 防卡死核对（对 §6 五条硬规则逐条自查）

1. **关键道具不可消耗/不可售/不可丢**：芯片、冷却剂、授权卡、磁力靴、焊接枪、星尘矿石 → 红框 ✓

3. **经济不枯竭也不失控**：洗碗/打下手可重复（都耗氧，换钱是兜底）；"劳动→买吃的"循环净收益为负（设计档 §8.1）✓
4. **失败条件始终可达**：氧气耗尽 → 44；被制服 → 29（星币不再判失败）✓
5. **引擎兜底**：无可执行选项且无可达编号 → 求救面板（回大厅 / 重开）✓（引擎 v0.2；v0.3 增补见设计档 §7）

### 8.1 序章与玩法说明

**序章（R01，99 字；正文唯一归属；机制见 `design-station-v1.md` §8.4）**：

> 你是{me}，趁暑假来『晨星号』实习的小孩，今天是第七天。
> 晚餐刚端上桌，灯"啪"地全灭了；警报小声说：空气在漏。
> 兜里的星币，能换吃的，也能换点小工具。
