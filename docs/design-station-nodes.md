## 1. 关卡目标与两条主线

- **总目标**：重启反应堆 → 揪出搞鬼的人。
- **重启需要三件东西**（各有两条以上拿法，防卡死）：

| 要点 | 路径① | 路径② |
|---|---|---|
| **控制芯片** | 帮老布找到他的工具箱（16 维修区）→ 老布给你 | 糖糖带你走维修爬道（16→7）去实验室自己拆 |
| **冷却剂** | 铁头帮你开仓库（10）硬拿 | 先拿到桑尼的账本（把柄）→ 逼他交出 |
| **站长授权卡** | 找到受伤的伊莲娜（3 医务室，需先送医疗包）→ 她给你 | 站长室（9）保险柜备卡——需先拿到密码（14 服务器机房 / 23 事件线） |

- **电力前置**：反应堆要有电才能启动 → 先去 **⑲ 太阳能板（舱外 EVA）** 修好被砸坏的一片面板（需磁力靴）。

## 3. 道具 · 线索 · 武力（20 件，图标见 `art/tasks/T06`）

- **工具**：手电、工牌、氧气瓶（+30 氧）、万能扳手、磁力靴、绳索
- **武力装备**：焊接枪(+1)、电击棒(+2)、机械手套(+1)、应急盾(+1)；敌人：失控维修机器人 1 / 安保机器人 3 / 桑尼的无人机 6
- **关键道具（红框·不可售不可丢）**：控制芯片、冷却剂罐、站长授权卡、星尘矿石（证据）
- **证据**：桑尼的账本（10 仓库）、监控回放（14 服务器机房）
- **线索**：反应堆规程、保险柜密码、走私暗号
- **消耗品**：站猫罐头（引开桑尼的猫/哄银河）、合成料理（+10 氧）、医疗包（给阿雅救站长）、备用电池
- **钱**：信用点 20（普通）/ 15（困难）；帮胖胖洗碗 +2（每次耗氧 5，**可重复**＝防卡死的收入兜底）；自动贩卖机在食堂

## 4. 氧气（新资源，本关失败条件之一）

- 初始 100；HUD 常驻显示；
- **消耗**：12 反应堆舱 −10/次、16 爬道 −10、19 舱外 −15、13 冷却塔泄漏区 −5、16 失控机器人战 −5
- **补给**（一次性）：氧气瓶 +30、3 医务室氧气站 +20、20 大厅补给柜 +15
- **失败**：氧 ≤ 0 →「眼前一黑……」失败结算
- **M4 验算目标**：主线必经消耗合计 ≤ 100 + 全部补给；每段主线保证有一处补给可达

## 6. 防卡死核对（对 §6 五条硬规则逐条自查）

1. **关键道具不可消耗/不可售/不可丢**：芯片、冷却剂、授权卡、磁力靴、焊接枪 → 红框 ✓
2. **每个门槛 ≥2 条解法**：三件重启物各 2 条（§1 表）✓；电力有 19 修面板一条 + （备用：13 冷却塔备件可换一罐冷却剂）✓
3. **经济可循环**：帮胖胖洗碗可重复（+2 信用点 / 耗氧 5，有代价、不会无限刷）✓；氧气补给 3 处一次性 + 料理回复 ✓
4. **失败条件始终可达**：氧/钱耗尽 → 44/45；被制服 → 29 ✓
5. **引擎兜底**：无可执行选项且无可达编号 → 求救面板（回大厅 / 重开）✓（引擎 v0.2）
