## 4. 氧气（唯一失败资源）

- 开局：普通 100 / **困难 30**；HUD 常驻显示**氧气条＋数值**（数值＝当前余量；B04 重订——`design-station-v1.md` §8.3／`design-ui-v1.md` §6）。
- **支出（每层都有）**：顶层 −25 ｜ 中层 −10 ｜ 底层 −40 ｜ 站外 −20（主线账面口径；逐段明细与预算表见 `design-station-v1.md` §8.2）。
- **补给（每处一次；毛额口径）**：睡眠舱氧气瓶 **+15**（翻找 −5 ⇒ 净 +10）、医务室氧气站 **+10**（搬运 −5 ⇒ 净 +5）、中层大厅补给柜 **+5**；热食：观景厅料理 +10、贩卖机料理 +10/盒（普通最多 4 盒 / 困难 3 盒）。**可得合计**：普通 100 + (15+10+5) + (10+40) = **180**；困难 30 + (15+10+5) + (10+30) = **100**（逐段表见 `design-station-v1.md` §8.2）。
- **失败**：氧 ≤ 0 → 44 号结算「眼前一黑……」。
- **验算结论**：普通结余 47.2%（≥30%）；困难结余 5.00%（≤5%）——困难必须拿满补给 + 吃掉热食 + 走主线。
