## 1. 做法与理由（一页）

- **全盘盘点，不止 13 条**：老板硬要求。本文件对 45/45 逐条走查（§6 总表 + §7 明细）：**改动 35 条 / 确认无问题 8 条 / 存疑 2 条**。

## 3. 人物卡（8 张）

> 每张卡 = 职业 / 性格 / 特点 / 能力 / 喜好 / 口头禅 / **不会说的话** / 关系。文案写作（含本文件 §7 与后续批次）按卡执行；对白长度、称呼、态度按卡区分。

**① 伊莲娜（站长）**
- 职业：站长。性格：铁面护短——话短、心热；对小孩会软三分。特点：全站授权最高的人，却最先倒下（原因留白）。能力：最高授权；保险柜备卡。喜好：站猫银河（她的猫）。
- 口头禅：没有废话；醒来第一句"反应堆……"。
- **不会说的话**：不会说客套话；不会对孩子说重话；不会写清楚自己藏东西的地方（"密码从不写下来"）。
- 关系：阿雅（主治）｜铁头（便条点名"他嘴硬，心不硬"）｜你（托付）。

**② 老布（总工程师）**
- 职业：总工程师。性格：零件控老头，说话绕圈子，爱哼歌。特点：红漆工具箱贴着"闲人勿动"；白胡子一翘一翘。能力：修一切（要配套零件）；人脉——铁头欠他三盒零件。喜好：零件、宝贝工具、汽水。
- 口头禅："我的宝贝！""免谈！""回头请你喝汽水！"
- **不会说的话**：不直说"帮我"，要绕着说；不说泄气话；不夸人，只会"嗯，还行"。
- 关系：铁头（欠他零件）｜糖糖（同为维修圈）｜你（打工换星币的小工）。

**③ 阿雅（医官）**
- 职业：医官。性格：冷静姐姐；话少、准。特点：换冰袋的细节控；站里人际门儿清。能力：医术（设备通电就能救人）；知道"密码从不写下来"。喜好：不写（保持专业距离）。
- 口头禅："她需要……""你先……"。
- **不会说的话**：不吓唬人；不八卦；不说"我也不知道"就不管（会给出下一个人名）。
- 关系：伊莲娜（病人）｜你（委托人）。

**④ 胖胖（厨师）**
- 职业：食堂主厨。性格：乐天派，慌的时候先喊"别慌别慌"。特点：零食袋藏在观景厅沙发后（被银河顺走）；把银河当小祖宗。能力：做饭（合成料理）／收废料（经济闭环）。喜好：吃的、真鱼罐头、热闹。
- 口头禅："别慌别慌！""帮我哄哄银河。"
- **不会说的话**：不抱怨站上条件；不叹气；不告状（"别跟别人说我偷吃"）。
- 关系：银河（投喂）｜你（发零工：洗碗 +2）。

**⑤ R2-糖糖（实习维修机器人）**
- 职业：实习维修机器人。性格：机灵、嘴快、爱表现。特点：圆眼睛、轮子划蓝光、"咔"地投清单、会留便签（"保险柜：0325，别忘啦"）。能力：记得站里每件事；带路（爬道）；知道密码。喜好：被夸、有活干。
- 口头禅："我知道站里的每一个角落！"
- **不会说的话**：不说丧气话；不说"我不知道"（它会说"我查一查"）。
- 关系：你（伙伴）｜伊莲娜（帮她设密码）｜老布（维修圈同事）。

**⑥ 铁头（安保队长）**
- 职业：安保队长。性格：直爽、爱较劲、耳朵软（被桑尼哄得团团转）。特点：哑铃不离手；安全门钥匙都在他手里。能力：开安全门／一把力气。喜好：举铁、掰手腕、听人夸。
- 口头禅："敢不敢？""行！""就这点劲儿？"
- **不会说的话**：不认怂；不拐弯抹角；输赢都摆在脸上。
- 关系：桑尼（被其蒙——"那哥们儿，热心！"）｜老布（欠零件）｜你（较劲后服气）。

**⑦ 桑尼（货运主管）**
- 职业：货运主管（仓库）。性格：笑眯眯、两面派。特点：人设是"热心肠"；真凶——偷运星尘矿石，断电是为掩护。能力：管货；无人机；封口费。喜好：面子、钱。
- 口头禅："小鬼，别多管闲事。""你会后悔的。"
- **不会说的话**：不当面骂人（笑着扎人）；不会露怯——直到被证据戳穿。
- 关系：铁头（骗）｜银河（本子被顺）｜你（威胁 / 收买 / 认栽）。

**⑧ 银河（站猫）**
- 职业：站猫（站长的猫）。性格：傲娇、认吃。特点：只吃真鱼（对合成粮闻都不闻）；爱叼小东西；总出现在出事的地方。能力：钻缝找路（猫的通道）；叼走账本（关键线索）。喜好：真鱼、零食袋、木星窗台。
- 口头禅：无台词——只写"喵 / 咕噜 / 尾巴"。
- **不会说的话**：不说话；任何文本不给它安排台词。
- 关系：伊莲娜（主人）｜胖胖（投喂）｜你（一手交鱼一手交本子）。
