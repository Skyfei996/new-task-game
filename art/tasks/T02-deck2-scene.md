# T02 · 中层「工作区」场景图

**交付路径**：`art/deliveries/T02-deck2-scene-v1.jpg`（多张用 v2、v3）
**风格基准**：`images/station/station-map-ai-v1.jpg`
**布局参考**：`images/station/blueprint-v1.jpg` 的**中层**

## 画面要求

把总览图里**中层（蓝色调的工作区）**单独画成一张大图：等距剖面、房间占满画面、细节丰富（屏幕光、仪表、货架、管线等）。

| 位置 | 房间 | 要点 |
|---|---|---|
| 左上 | 指挥舱 | 弧形控制台 + 发光大屏 + 座椅 |
| 中上 | 实验室 | 实验台、冒泡的烧瓶（青绿色液体）、显微镜 |
| 右上 | 通讯舱 | 巨大的卫星天线碟（朝窗外）、机柜 |
| 左下 | 站长室 | 办公桌 + 台灯 + 盆栽 + 保险柜 |
| 中下 | 仓库 | 成堆货箱与油桶、叉车/手推车 |
| 右下 | 气闸舱 | 圆形舱门、挂着的宇航服、收纳柜 |

**绝对不要**：文字/数字/标签/水印；不要画其它两层的内容。

**尺寸**：宽 1600~2048px（横构图），单图 ≤ 1.5MB。
