## 画面要求

把总览图里**最下层（青绿色调的核心区）**单独画成一张大图：等距剖面、房间占满画面；这是全关最重要的机械层，细节要足（管线、阀门、警示条纹、仪表、蒸汽）。

| 位置 | 房间 | 要点 |
|---|---|---|
| 左上 | 反应堆舱 | **发光的反应堆核心**（青色光晕、环形结构、警示围栏）——全图视觉中心 |
| 中上 | 冷却塔 | 两根粗管道 + 白色蒸汽 + 压力表 |
| 右上 | 服务器机房 | 成排机柜 + 闪烁指示灯 + 盘绕的线缆 |
| 左下 | 太阳能控制室 | 墙面大控制面板 + 操作台 + 椅子 |
| 中下 | 维修区（爬道口） | 爬梯 + 打开的检修口 + 工具箱 + **一台可爱的小机器人** |
| 右下 | 应急逃生舱 | 金色逃生舱（胶囊形）+ 发射口 + 警示条 |

**绝对不要**：文字/数字/标签/水印；不要画其它两层的内容。

**尺寸**：宽 1600~2048px（横构图），单图 ≤ 1.5MB。
